5.1 Introduction to Uncertainty in AI & SLAM

Topic 5.1 Theory
Why Classical Logic Fails in Real World: Classical logic assumes clean, binary (True/False), complete facts. Rule-based systems become brittle on unseen cases and cannot weigh risks.
Rational Decision Rule: Weigh Probability + Consequence (e.g., Self-driving car: Action A = 95% safe / 5% crash vs Action B = Stop → 100% safe, slight delay).
7 Sources of Uncertainty in AI Meaning & Slide Example
1. Incomplete Information Missing access to all facts (e.g., medical system lacking full patient history).
2. Sensor / Measurement Noise Cameras, LiDAR, GPS, thermometers have physical measurement errors.
3. Ambiguity in Data Multiple valid interpretations (e.g., word "bank" = financial vs riverbank).
4. Non-deterministic / Stochastic Same action yields different outcomes (rolling dice, weather prediction).
5. Limitations of the Model AI models are simplifications of reality and omit hidden variables.
6. Exceptions & Rare Events Unseen edge cases not covered during rule design or training.
7. Conflicting Evidence Different sensors or information sources disagree with each other.

Slide Case Study: Robotics SLAM (Simultaneous Localization & Mapping)

  • The Dual Problem: Robot in an unknown building must simultaneously know 1. Localization (Where am I?) and 2. Mapping (What does my environment look like?).
  • Numerical Slide Example: Robot starts at (0, 0) and moves forward 5 m (ideal: (5, 0)).
    • Wheel slip causes odometry to estimate (4.8, 0.2) → Localization Uncertainty.
    • LiDAR measures a wall at 9.8 m instead of actual 10 m → Mapping Uncertainty.

5.1 Probability Fundamentals & The 3 Axioms

Topic 5.1 Basics

Core Definitions

  • Random Variable: Variable taking values with probabilities. Can be Discrete (coin toss: H/T) or Continuous (temperature, height).
  • Sample Space (S): Set of all possible outcomes. Die roll: S = {1, 2, 3, 4, 5, 6}.
  • Event: Subset of S (e.g., Even = {2, 4, 6}).

Probability Scale [0, 1]

  • P(Event) = 0 → Event is Impossible (P(∅) = 0).
  • P(Event) = 1 → Event is Certain.
  • 0 < P(Event) < 1 → Uncertain degree of belief.
Axiom / Property Mathematical Formula Slide Die-Roll Verification (S = {1, 2, 3, 4, 5, 6})
Axiom 1: Non-Negativity P(A) ≥ 0 Let A = Even = {2, 4, 6} ⇒ P(A) = 3/6 = 1/2 ≥ 0 (Never negative).
Axiom 2: Normalization P(S) = 1 One of the 6 faces must appear ⇒ P(S) = 6/6 = 1.
Axiom 3: Additivity
(Mutually Exclusive)		 If A ∩ B = ∅:
P(A ∪ B) = P(A) + P(B)		 Let C = {1}, D = {6} (C ∩ D = ∅).
P(C ∪ D) = 1/6 + 1/6 = 2/6 = 1/3.
Complement Rule P(¬A) = 1 - P(A) ¬A = {1, 3, 5} ⇒ P(¬A) = 1 - 1/2 = 1/2.

5.1 Master Formula Table: Joint, Marginal, Conditional, Product, Chain & Independence

Core Formulas
Rule / Concept Formula When to Use & Slide Worked Examples
1. Addition Rule (Overlapping Events) P(A ∪ B) = P(A) + P(B) - P(A ∩ B) Die Example: A = Even {2,4,6}, B = Greater than 3 {4,5,6}. Overlap A ∩ B = {4,6}.
P(A ∪ B) = 3/6 + 3/6 - 2/6 = 4/6 = 2/3.
Weather Example: P(Rain)=0.30, P(Cloudy)=0.50, P(R ∩ C)=0.20 ⇒ P(R ∪ C) = 0.30 + 0.50 - 0.20 = 0.60.
2. Joint Probability P(A, B) = P(A ∩ B) Probability that both A and B happen together (e.g., P(Rain, Traffic)).
3. Marginal Probability (Marginalization) P(A) = ∑B P(A, B) = P(A, B) + P(A, ¬B) Probability of a single event obtained by summing over all possible values of the other variable(s).
4. Conditional Probability P(A | B) = P(A ∩ B) / P(B)   (for P(B) > 0) Die Example: Roll > 4 (A={5,6}) given Even (B={2,4,6}): P(A ∩ B)=1/6, P(B)=3/6 ⇒ P(A|B) = (1/6)/(3/6) = 1/3.
Weather Example: P(Rain | Cloudy) = P(Rain ∩ Cloudy) / P(Cloudy) = 0.20 / 0.50 = 0.40 (40%).
5. Multiplication / Product Rule (Dependent) P(A ∩ B) = P(A) · P(B | A) = P(B) · P(A | B) Bag Without Replacement: 5 Red, 3 Blue balls (Total 8). Draw 2 Red:
P(R1) = 5/8, P(R2 | R1) = 4/7 ⇒ P(R1 ∩ R2) = (5/8) × (4/7) = 20/56 = 5/14.
6. Multiplication Rule (Independent) P(A ∩ B) = P(A) · P(B)   iff   P(A | B) = P(A) Occurrence of A does not affect B.
• Two coin tosses (both Heads): 1/2 × 1/2 = 1/4.   • Coin Heads & Die 6: 1/2 × 1/6 = 1/12.
7. Chain Rule (Multiple Variables) P(X1, X2, ..., Xn) = P(X1) · P(X2 | X1) · P(X3 | X1, X2) ... Breaks complex joint distributions into a product of conditional probabilities (foundation of Bayesian Networks).
8. Conditional Independence P(A, B | C) = P(A | C) · P(B | C)
or P(A | B, C) = P(A | C)		 Once C (e.g., Disease status) is known, knowing B (Test result) gives no extra info about A (Doctor's check).

Slide Worked Table: 1,000 Patients Tested

  • Row 1 (Disease A): Pos (B) = 80 | Neg (¬B) = 20 | Row Total = 100
  • Row 2 (No Disease ¬A): Pos (B) = 90 | Neg (¬B) = 810 | Row Total = 900
  • Column Totals: Pos (B) = 170 | Neg (¬B) = 830 | Grand Total = 1000
  • 1. Joint P(A ∩ B): Disease AND Pos = 80 / 1000 = 0.08 (8%)
  • 2. Marginal P(A): Disease alone = 100 / 1000 = 0.10 (10%)
  • 3. Conditional P(A | B): Disease given Pos = (80/1000) / (170/1000) = 80/170 = 47.06%

Slide 5-Part Problem: Disease (S), Test (T), Doctor (D)

  • Given: P(S)=0.02, P(T|S)=0.95, P(T|¬S)=0.03, P(D|S)=0.85, P(D|¬S)=0.05
  • 1. Product Rule P(S ∩ T): 0.95 × 0.02 = 0.019 (1.9%)
  • 2. Marginal P(T): 0.019 + (0.03 × 0.98) = 0.019 + 0.0294 = 0.0484 (4.84%)
  • 3. Bayes P(S | T): 0.019 / 0.0484 ≈ 0.3926 (39.26%)
  • 4. Chain Rule P(S, T, D): 0.02 × 0.95 × 0.85 = 0.01615 (1.615%)
  • 5. Cond. Indep. P(T, D | S): P(T|S) × P(D|S) = 0.95 × 0.85 = 0.8075 (80.75%)
PYQ B1 Q4b Exam Pattern — 2×2×2 Joint Probability Table (Rain, Wind, Headache):
• Given a 3-variable joint table P(R, W, H), first sum cells to get marginals: e.g., P(W) = 0.432 + 0.16 + 0.16 + 0.048 = 0.80, P(R) = 0.432 + 0.16 + 0.084 + 0.072 = 0.748.
• To check if Wind increases given Rain: compare P(W | R) = P(W ∩ R) / P(R) against P(W). If P(W | R) = P(W), they are Independent; if unequal, they are Dependent.
• To check if Rain is conditionally independent of Headache given Wind: test if P(R, H | W) = P(R | W) × P(H | W).

5.2 Bayes' Rule Architecture & Base Rate Fallacy

Topic 5.2 Core
Bayes' Theorem:   P(H | E) = [ P(E | H) · P(H) ] / P(E)
Expanded (Law of Total Probability):
P(H | E) = [ P(E | H) · P(H) ] / [ P(E | H)·P(H) + P(E | ¬H)·P(¬H) ]
Belief Revision Engine:   Posterior ∝ Likelihood × Prior
Term Name Meaning & Medical Test Equivalent
P(H) Prior Probability Initial belief in hypothesis H before seeing evidence (Base rate / disease prevalence in population).
P(E | H) Likelihood Probability of observing evidence E assuming H is true. In medicine: Sensitivity (True Positive Rate).
P(E | ¬H) False Positive Rate Probability of observing evidence E when H is false.
Trap: P(+ | ¬Disease) = 1 - Specificity!
P(E) Evidence (Marginal) Normalizing constant across all hypotheses so posteriors sum to 1: P(E|H)P(H) + P(E|¬H)P(¬H).
P(H | E) Posterior Probability Updated belief in hypothesis H after incorporating evidence E.
The Base Rate Fallacy (Slide Highlight):
When a condition is very rare (low prior P(H) = 1%), even a test with 95% sensitivity and 90% specificity gives only an 8.76% posterior chance of actually having the disease! Why? Because 10% false positives across the massive 99% healthy population (0.099) outnumber true positives from the tiny 1% sick population (0.0095) by more than 10-to-1.

5.2 Applying Bayes' Rule with Multiple Evidences & Naive Bayes Classification

83.3% PYQ Probability (10 Marks)
Naive Bayes Conditional Independence Assumption: Features E1, E2, ..., Ek are conditionally independent given the class H:
1. Combined Likelihood for Class H:   P(E1, E2, ..., Ek | H) = P(E1 | H) × P(E2 | H) × ... × P(Ek | H)
2. Combined Likelihood for Class ¬H:   P(E1, E2, ..., Ek | ¬H) = P(E1 | ¬H) × P(E2 | ¬H) × ... × P(Ek | ¬H)
3. Evidence Denominator P(E):   P(E) = P(E1..Ek | H)·P(H) + P(E1..Ek | ¬H)·P(¬H)
4. Posterior Probability:   P(H | E1..Ek) = [ P(E1..Ek | H) · P(H) ] / P(E)

PYQ Tabular Naive Bayes Recipe (B1, B2, D1, D2, E1)

  • Step 1 (Priors): Count rows per class: P(C_k) = Count(C_k) / Total_Rows.
  • Step 2 (Likelihoods): For each query attribute x_i, count how many rows in class C_k have x_i: P(x_i | C_k) = Count(x_i ∩ C_k) / Count(C_k).
  • Step 3 (Class Score): Multiply Score(C_k) = P(C_k) × ∏ P(x_i | C_k).
  • Step 4 (Zero-Count / Laplace Smoothing): If any Count(x_i ∩ C_k) = 0, state raw score is 0 AND show Laplace smoothed probability: (count + 1) / (Count(C_k) + num_distinct_values).
