KRR Architecture & Knowledge-Based Agent Cycle Slides 6–9, 67–75

1. Perceive→ 2. TELL (KB)→ 3. Infer / ASK (KB)→ 4. Act
Component / Level Definition & Role Examples

5 Types of Knowledge & KB vs. Database Slides 10–13, 68–71
Knowledge Type Core Meaning Example
1. Declarative "Know What" — static facts, concepts, objects. Capital(TamilNadu, Chennai), Water boils at 100°C.
2. Procedural "Know How" — imperative steps, algorithms, strategies to perform tasks. Algorithm to compute circle area: obtain $r$, compute $A = \pi r^2$.
3. Meta-Knowledge "Knowledge about Knowledge" — reliability, rule priority, confidence. "Apply Rule 1 before Rule 2", "Source A is reliable".
4. Heuristic "Rule of Thumb" — expert experience; fast & useful, not guaranteed. "Control center of chessboard", "Check battery first if laptop won't boot".
5. Structural Relationships organizing concepts/objects. IS-A (Car IS-A Vehicle), PART-OF (Engine PART-OF Car).
KB vs. Database: A Database stores large volumes of flat facts on disk (updated by clerks, retrieves data only, implicit rules). A Knowledge Base stores explicit facts + rules in main memory (updated by domain experts, actively infers new conclusions).

Models, Entailment ($KB \models \alpha$), Soundness & Completeness Slides 17–18, 86–95, 103–104
Term / Symbol Formal Definition & Exam Key Point
Syntax vs. Semantics Syntax: What expressions are legally formed ($x+2 \ge y$). Semantics: Truth meaning of a sentence in a possible world.
Model ($m$) & $M(\alpha)$ A possible world assigning T/F to every variable ($n$ vars $\Rightarrow 2^n$ models). $M(\alpha)$ is the set of all models where $\alpha$ is True.
Logical Entailment ($KB \models \alpha$) $\alpha$ logically follows from $KB$: in every model where $KB$ is True, $\alpha$ is also True. Formally: M(KB) ⊆ M(α).
Entailment ($\models$) vs. Implication ($\rightarrow$) P → Q is a syntactic formula inside logic; KB ⊨ Q is a semantic meta-relationship between KB and conclusion.
Soundness ($KB \vdash_i \alpha \Rightarrow KB \models \alpha$) Inference procedure $i$ is sound if it proves only true statements (never proves anything wrong).
Completeness ($KB \models \alpha \Rightarrow KB \vdash_i \alpha$) Inference procedure $i$ is complete if it can prove every sentence that is logically entailed by KB.
PYQ Entailment Trick (Slot B1 Q3b): Adding a disjunct weakens a clause so it IS entailed: $(A \vee B)$ entails $(A \vee B \vee C)$. Removing a literal from a clause strengthens it so it is NOT entailed: $(\neg C \vee \neg D \vee E)$ does not entail $(\neg D \vee E)$!

Tricky English Phrases → Propositional Logic Mapping Slides 57–61
English Phrase Pattern Formal Translation Why / Memory Rule
"A if B" B → A B is the trigger/cause for A. (e.g., "I pass if I study": $\text{Study} \rightarrow \text{Pass}$).
"A only if B" A → B TRAP! B is a necessary condition for A. ("I pass only if I study": $\text{Pass} \rightarrow \text{Study}$).
"A unless B" ¬B → A $\equiv$ A ∨ B "If not B, then A" ("Walk unless it rains": $\neg\text{Rain} \rightarrow \text{Walk}$).
"A if and only if (iff) B" A ↔ B Both directions hold: $(A \rightarrow B) \wedge (B \rightarrow A)$.
"Neither A nor B" ¬A ∧ ¬B $\equiv$ ¬(A ∨ B) Both A and B are false (De Morgan's Law).
"Either A or B, but not both" (A ∨ B) ∧ ¬(A ∧ B) Exclusive OR (XOR).
"A, but B" / "A, yet B" / "A, moreover B" A ∧ B "But", "yet", "also" always translate to logical AND ($\wedge$)!
Laws of Logical Equivalence ($\alpha \equiv \beta$) Slides 41–44, 105, 111
Law Name Formal Equivalence Formula
Implication Elimination (α ⇒ β) ≡ (¬α ∨ β) (Most used law in CAT-2!)
Contraposition (Contrapositive) (α ⇒ β) ≡ (¬β ⇒ ¬α) (e.g., $\neg\text{Sunny} \Rightarrow \text{Umbrella} \equiv \neg\text{Umbrella} \Rightarrow \text{Sunny}$)
Biconditional Elimination (α ⇔ β) ≡ (α ⇒ β) ∧ (β ⇒ α)
De Morgan's Laws ¬(α ∧ β) ≡ (¬α ∨ ¬β)  and  ¬(α ∨ β) ≡ (¬α ∧ ¬β)
Distributivity (∨ over ∧ for CNF) α ∨ (β ∧ γ) ≡ (α ∨ β) ∧ (α ∨ γ)
Distributivity (∧ over ∨ for DNF) α ∧ (β ∨ γ) ≡ (α ∧ β) ∨ (α ∧ γ)
Double Negation & Commutativity ¬(¬α) ≡ α  |  (α ∧ β) ≡ (β ∧ α)  |  (α ∨ β) ≡ (β ∨ α)
Nested Implication Exportation α ⇒ (β ⇒ γ) ≡ (α ∧ β) ⇒ γ (Used in Marcus BC slide 89!)
CNF vs. DNF Quick Check (Slides 41–42):
• CNF (Conjunctive Normal Form): AND outside, OR inside $\rightarrow (A \vee B) \wedge (\neg P \vee Q)$.
• DNF (Disjunctive Normal Form): OR outside, AND inside $\rightarrow (A \wedge B) \vee (\neg P \wedge Q)$.
Validity, Satisfiability & 5 Propositional Inference Rules Slides 34–40, 101–106, 110
Concept / Rule Formula / Structure Key Meaning & Memory Trick
Valid (Tautology) True in ALL models ($T, T, \dots, T$) Deduction Theorem: $KB \models \alpha \iff (KB \Rightarrow \alpha)$ is Valid.
Satisfiable True in $\ge 1$ model Every valid formula is also satisfiable! If true in some & false in some = Contingency.
Unsatisfiable (Contradiction) True in NO models ($F, F, \dots, F$) Refutation Theorem: $KB \models \alpha \iff (KB \wedge \neg\alpha)$ is Unsatisfiable (Basis of Resolution!).
1. Modus Ponens (MP) P → Q,  P  ∴ Q Confirm the cause $\rightarrow$ get the result.
2. Modus Tollens (MT) P → Q,  ¬Q  ∴ ¬P Deny the conclusion $\rightarrow$ reject the cause. (Note: $P \rightarrow Q, Q \therefore P$ is INVALID!).
3. Hypothetical Syllogism (HS) P → Q,  Q → R  ∴ P → R Chain Rule of implications.
4. Disjunctive Syllogism (DS) P ∨ Q,  ¬P  ∴ Q Unit Resolution: Eliminate one option in OR $\rightarrow$ keep the other.
5. Resolution Rule P ∨ Q,  ¬P ∨ R  ∴ Q ∨ R Cancel complementary literals ($P, \neg P$) and join remaining disjuncts.
Topics 4.4 & 4.5 First-Order Logic (FOL): Syntax, Quantifiers & High-Yield Translations
Probability: 100% (Guaranteed 4–10 Marks)
Propositional Logic vs. First-Order Logic & FOL Syntax Slides 27–31, 152–158
Feature Propositional Logic (PL) First-Order Logic (FOL)
Ontology (World View) Atomic Facts ($P, Q, R$) Objects, Properties (Unary Predicates), Relations ($n$-ary), Functions
Syntax Building Blocks Proposition symbols + Connectives ($\neg, \wedge, \vee, \rightarrow, \leftrightarrow$) Terms (Constants, Variables, Functions) + WFF Sentences (Predicates, Quantifiers $\forall, \exists$, $=$)
Predicate vs. Function N/A Predicate returns True/False (Tall(John)). Function returns an Object (FatherOf(Mary) = John).
Inference & Complexity Truth Tables, DPLL, GSAT — NP-Complete (Decidable) Unification, GMP, FC/BC, Resolution — Semi-decidable (Infinite interpretations if functions exist)
Ground Term vs. WFF (Slide 158): A Ground Term has NO variables (e.g., FatherOf(John)). A Well-Formed Formula (WFF) has NO "free" variables—every variable is bound by $\forall$ or $\exists$.
Quantifier Golden Rules, Scope & De Morgan's Duality Slides 30, 49–50, 159–162
Rule / Property Universal Quantifier ($\forall x$) Existential Quantifier ($\exists x$)
Standard Connective Pairs with Implication ($\rightarrow$):
∀x (Elephant(x) → Gray(x))		 Pairs with Conjunction ($\wedge$):
∃x (Student(x) ∧ Smart(x))
Fatal Exam Mistake! NEVER write ∀x (Elephant(x) ∧ Gray(x)) (Means everything in universe is a gray elephant!). NEVER write ∃x (Student(x) → Smart(x)) (Trivially true if a non-student object exists!).
Swapping Quantifiers • Same quantifiers commute: ∀x ∀y P(x,y) ⇔ ∀y ∀x P(x,y) and ∃x ∃y P(x,y) ⇔ ∃y ∃x P(x,y).
• Mixed quantifiers DO NOT commute:
  ∀x ∃y Likes(x,y) = "Everyone likes someone" $\neq$ ∃y ∀x Likes(x,y) = "Someone is liked by everyone".
De Morgan's Quantifier Laws • ¬∀x P(x) ⇔ ∃x ¬P(x)   |   ∀x ¬P(x) ⇔ ¬∃x P(x)
• ¬∃x P(x) ⇔ ∀x ¬P(x)   |   ∃x P(x) ⇔ ¬∀x ¬P(x)

Topic 4.6 Inference in First-Order Logic, Instantiation Rules & Unification (MGU)
Probability: 83.3% (Core to Chaining & Resolution)
4 Quantified Inference Rules (UI, EI, UG, EG) Slides 62–64, 163–166, 174–175
Rule Name Inference Form Restriction & Example
1. Universal Instantiation (UI)
(Universal Elimination)		 $$\frac{\forall v \; \alpha}{\text{Subst}(\{v/g\}, \alpha)}$$ Everyone $\rightarrow$ One: Replace $v$ with any ground term $g$ (constant or ground function like Father(John)). Can be applied multiple times.
2. Existential Instantiation (EI)
(Existential Elimination / Skolemization)		 $$\frac{\exists v \; \alpha}{\text{Subst}(\{v/k\}, \alpha)}$$ Someone exists $\rightarrow$ Give a brand-new name: Replace $v$ with a Skolem constant $k$ that does not appear anywhere else in KB. Applied once, then discard $\exists$.
3. Universal Generalization (UG) $$\frac{P(x) \text{ (for arbitrary } x\text{)}}{\forall x \; P(x)}$$ Arbitrary one $\rightarrow$ Everyone: If proven for an arbitrary variable $x$, generalize to $\forall x$.
4. Existential Generalization (EG)
(Existential Introduction)		 $$\frac{P(a)}{\exists x \; P(x)}$$ One known object $\rightarrow$ Someone exists: From Student(Ravi), infer ∃x Student(x).
Propositionalization Problem (Slides 176–178): Converting FOL to PL via UI generates irrelevant facts (e.g., Greedy(Richard)) and becomes infinite when function symbols exist (Father(Father(Father(John)))). Unification + Generalized Modus Ponens solves this!
Unification Algorithm & Most General Unifier (MGU) Slides 65–67, 179–189

UNIFY(p, q) = θ returns the Most General Unifier (MGU) substitution $\theta$ such that $p\theta = q\theta$.

  • Condition 1: Predicate symbols must be identical (Likes cannot unify with Knows).
  • Condition 2: Number of arguments must be identical.
  • Condition 3 (Conflict / Occurs Check): A variable cannot unify with two different constants in the same scope, nor with a function of itself (e.g., $x$ with $f(x)$).
Expression $p$ Expression $q$ MGU $\theta = \text{UNIFY}(p, q)$
Knows(John, x) Knows(John, Jane) {x / Jane}
Knows(John, x) Knows(y, OJ) {y / John, x / OJ}
Knows(John, x) Knows(y, Mother(y)) {y / John, x / Mother(John)}
Knows(John, x) Knows(x, OJ) FAIL ($x$ cannot be both John and OJ! Must standardize apart to $x_1, x_2$ first).
Knows(John, x) Knows(y, z) {y / John, x / z} (More general than $\{y/\text{John}, x/\text{John}, z/\text{John}\}$)
Topic 4.7 Forward Chaining vs. Backward Chaining & Horn Clauses
Probability: 66.7% (6–10 Marks)
Horn Clauses & Forward vs. Backward Chaining Comparison Slides 68–80, 94, 121–145, 196–207
• Horn Clause: Disjunction with at most 1 positive literal: e.g., (¬C ∨ ¬B ∨ A) or (¬P ∨ ¬W).
• Definite Clause: Disjunction with exactly 1 positive literal ≡ Implication: (C ∧ B ⇒ A) or Fact: A.
• Datalog KB: First-order definite clauses + NO functions (FC guaranteed to terminate!).
Feature Forward Chaining (FC) Backward Chaining (BC)
Reasoning Style Data-Driven (Bottom-Up, automatic) Goal-Driven (Top-Down, depth-first search)
Direction Known Facts → Fire Rules → Goal Goal Query → Subgoals (Premises) → Known Facts
Main Question "What new facts can I derive from what I know?" "What premises do I need to prove this specific goal?"
Time Complexity Linear in size of Horn KB, but derives many irrelevant facts. Often much less than linear (only touches relevant rules). Space is linear in proof depth.
Pitfalls & Fixes Redundant rule matching $\rightarrow$ Fix with Incremental FC & database indexing. Infinite loops & repeated subgoals $\rightarrow$ Fix by checking goal stack & caching (tabling).
Best Used For Expert monitoring, reactive systems, deductive databases. Diagnostic queries, Prolog, theorem proving for a single query.
Colonel West Case Study & PYQ Working Memory Format Slides 70–74, 190–206 + PYQs B2/E1

Colonel West KB Rules & Facts (Slides 71–74, 191):

R1: American(x) ∧ Weapon(y) ∧ Sells(x,y,z) ∧ Hostile(z) ⇒ Criminal(x)
R2: Missile(x) ∧ Owns(Nono, x) ⇒ Sells(West, x, Nono)
R3: Missile(x) ⇒ Weapon(x)  |  R4: Enemy(x, America) ⇒ Hostile(x)
Facts: American(West), Owns(Nono, M₁), Missile(M₁), Enemy(Nono, America)

Forward Chaining Iterations (Bottom-Up):
• Iter 1: Fire R3 with {x/M₁} $\rightarrow$ add Weapon(M₁); Fire R2 with {x/M₁} $\rightarrow$ add Sells(West, M₁, Nono); Fire R4 with {x/Nono} $\rightarrow$ add Hostile(Nono).
• Iter 2: Fire R1 with {x/West, y/M₁, z/Nono} $\rightarrow$ derive Criminal(West)! (Fixed point reached).

Backward Chaining Tree (Top-Down):
• Goal Criminal(West) unifies with head of R1 {x/West} $\rightarrow$ Subgoals: American(West) (Fact ✓), Weapon(y) $\rightarrow$ R3 Missile(y) $\rightarrow$ Fact Missile(M₁) ✓ {y/M₁}, Sells(West, M₁, z) $\rightarrow$ R2 $\rightarrow$ Facts ✓ {z/Nono}, Hostile(Nono) $\rightarrow$ R4 $\rightarrow$ Fact ✓.

How to Write PYQ Working Memory Answers (Fluffy Tiger / Speedster Motorcycle):
Always write: R1: ?x gives milk → Fluffy gives milk (succeeds due to A4) → WM := WM + {A6: Fluffy is a mammal}. If a premise is missing (e.g., Whiskers lays eggs), explicitly write: fails → hence R2 is not triggered!
Topic 4.8 6-Step FOL-to-CNF Pipeline, Skolemization & Resolution Refutation Proofs
Probability: 83.3% (6–10 Marks)
6-Step FOL-to-CNF Conversion Pipeline (With Skolemization Rules) Slides 83, 96–97, 111
Step Rule / Action Worked Transformation Example
Step 1 Eliminate Biconditionals ($\Leftrightarrow$) $\alpha \Leftrightarrow \beta \;\longrightarrow\; (\alpha \Rightarrow \beta) \wedge (\beta \Rightarrow \alpha)$
Step 2 Eliminate Implications ($\Rightarrow$) $\alpha \Rightarrow \beta \;\longrightarrow\; \neg\alpha \vee \beta$
Trap: $(A \vee B) \Rightarrow C$ becomes $(\neg A \vee C) \wedge (\neg B \vee C)$ (2 clauses!).
Step 3 Move Negation Inwards ($\neg$) Apply De Morgan's & Quantifier Negation:
$\neg\forall x\, P(x) \rightarrow \exists x\,\neg P(x)$  |  $\neg\exists x\, P(x) \rightarrow \forall x\,\neg P(x)$
Step 4 Standardize Variables Apart Rename dummy variables so each quantifier has a unique variable: $(\forall x\, P(x)) \vee (\forall x\, Q(x)) \rightarrow (\forall x\, P(x)) \vee (\forall y\, Q(y))$.
Step 5 Skolemization (Eliminate $\exists$) • Case A (No outer $\forall$): Replace $\exists x$ with a new Skolem Constant $c$: $\exists x\, Student(x) \rightarrow Student(c)$.
• Case B ($\exists y$ inside $\forall x$): Replace $y$ with a Skolem Function $f(x)$: $\forall x \exists y\, LoyalTo(x,y) \rightarrow \forall x\, LoyalTo(x, f(x))$.
Step 6 Drop $\forall$ & Distribute $\vee$ over $\wedge$ Omit $\forall$ quantifiers and distribute $A \vee (B \wedge C) \rightarrow (A \vee B) \wedge (A \vee C)$ to get clauses.

C1: Man(Marcus)  |  C2: Pompeian(Marcus)  |  C3: ¬Pompeian(x) ∨ Roman(x)

C6: LoyalTo(x, f(x))  [From ∀x ∃y LoyalTo(x,y)]
C7: ¬Man(x) ∨ ¬Ruler(y) ∨ ¬TryAssassinate(x,y) ∨ ¬LoyalTo(x,y)

Module 3 (Topic 3.4): Game Trees, Minimax & Alpha-Beta Pruning 100% Guaranteed Q1 (10 Marks)
Concept / Parameter Rule / Formula
Maximizer Node (MAX) Picks highest child value: $V(s) = \max_{s' \in \text{children}(s)} V(s')$. Updates $\alpha = \max(\alpha, V)$.
Minimizer Node (MIN) Picks lowest child value: $V(s) = \min_{s' \in \text{children}(s)} V(s')$. Updates $\beta = \min(\beta, V)$.
Initial Bounds at Root $\alpha = -\infty$ (best already guaranteed for MAX along path), $\beta = +\infty$ (best already guaranteed for MIN along path).
Pass Down vs. Pass Up $\alpha$ and $\beta$ values are passed DOWN to children; backed-up node values $V$ are passed UP to parents.
Pruning Condition Prune remaining sibling branches whenever $\alpha \ge \beta$ (or $V \le \alpha$ at a MIN node / $V \ge \beta$ at a MAX node).
3 Exam Checkpoints for Q1:
1. Check if the root player is MAX (default) or MIN (Slot E2 2024 started with MIN at root!).
2. Check traversal order: Left-to-Right vs. Right-to-Left (Slot D1 2025 asked both!).
3. Always write 1 sentence per pruned branch: "Pruned node X because $\beta = -2 \le \alpha = 4$" (Worth 2 marks!).

Formula Name Mathematical Expression & Usage
Conditional Probability $$P(A \mid B) = \frac{P(A \wedge B)}{P(B)} \quad \Longleftrightarrow \quad P(A \wedge B) = P(A \mid B) P(B)$$
Statistical Independence $A$ and $B$ are independent iff: $P(A \mid B) = P(A)$  or  $P(A \wedge B) = P(A) P(B)$.
Bayes' Theorem (Total Prob) $$P(H \mid E) = \frac{P(E \mid H) P(H)}{P(E)} = \frac{P(E \mid H) P(H)}{P(E \mid H) P(H) + P(E \mid \neg H) P(\neg H)}$$
Multiple Conditional Indep. Symptoms
(Slot D2 Q4A Flu/Fever/Cough)		 If $V, C$ conditionally independent given $F$:
$P(V \wedge C \mid F) = P(V \mid F) \times P(C \mid F)$ and $P(V \wedge C \mid \neg F) = P(V \mid \neg F) \times P(C \mid \neg F)$.
Naive Bayes Classifier
(Tabular Dataset Prediction)		 For query features $X = (x_1, x_2, \dots, x_n)$, compute score for each class $C_k$:
$$\text{Score}(C_k) = P(C_k) \times \prod_{i=1}^{n} P(x_i \mid C_k)$$ Pick class $C_k$ with maximum score!
Bayesian Belief Network (DAG) Joint probability of all nodes: $P(X_1, \dots, X_n) = \prod_{i=1}^{n} P(X_i \mid \text{Parents}(X_i))$.
