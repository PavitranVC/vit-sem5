Mod 2 A* Search & UCS Algorithm
10 Marks ▼

Core Formula

f(n) = g(n) + h(n)

  • g(n): Exact cumulative path cost from start node S to current node n.
  • h(n): Heuristic estimated cost from node n to Goal. (In UCS, h(n) = 0).
🚨 #1 Answer Key Trap: Goal test is executed when the Goal node is DEQUEUED (expanded) from the OPEN list, NOT when it is generated!

Admissibility & Consistency (HOT Questions)

  • Admissible: h(n) ≤ h*(n) (Never overestimates true cost. Guarantees optimality in tree search).
  • Consistent (Monotonic): h(n) ≤ c(n, a, n') + h(n') (Triangle inequality. Guarantees that nodes never need to be reopened from CLOSED list).
Mod 2 8-Puzzle Solvability & Heuristics
10 Marks ▼

1. Solvability Rule (Inversion Parity)

Rule: Flatten grid into a row, completely ignore the blank tile (_). Count how many times a larger number appears before a smaller number.
Inversions(Initial) ≡ Inversions(Goal) (mod 2)
Both EVEN or both ODD &implies; SOLVABLE. One Even and one Odd &implies; IMPOSSIBLE!

2. The Two Heuristics: h1 vs h2

  • h1 (Misplaced Tiles): Count how many tiles (1 to 8) are NOT in their assigned goal chair.
  • h2 (Manhattan Distance): For each tile, count grid steps (horizontal + vertical) to reach its goal position: |r1 - r2| + |c1 - c2|. Sum for all 8 tiles.

Dominance Proof: h2(n) ≥ h1(n) for all states. Therefore, Manhattan distance dominates misplaced tiles &implies; A* expands fewer nodes and runs faster.

Mod 3 Minimax & Alpha-Beta Pruning
10 Marks ▼

The 2 Rules of Alpha-Beta Pruning

  • α (Alpha): Best guaranteed score for MAX so far (initially α = -∞). Updated only at MAX nodes: α = max(α, child).
  • β (Beta): Best guaranteed score for MIN so far (initially β = +∞). Updated only at MIN nodes: β = min(β, child).
✂️ THE CUTOFF CONDITION: Whenever α ≥ β, PRUNE immediately! Do not evaluate remaining children of that node. Put a slash on your diagram.

Move Ordering Complexity (HOT Question)

  • Worst Case (Worst moves evaluated first): No pruning &implies; O(b^d).
  • Best Case (Best moves evaluated first): Maximum pruning &implies; O(b^(d/2)) (Doubles search depth!).
Mod 3 Hill Climbing & Failure Modes
10 Marks ▼

Core Mechanism

Greedy local search. Keeps only 1 state in memory. Evaluates neighbors and steps toward whichever neighbor is higher. Stops when no neighbor is higher.

3 Failure Modes (Draw these on exam!)

  • Local Maximum: Peak higher than all neighbors, but lower than global maximum. Search gets trapped.
  • Plateau / Shoulder: Flat area where all neighbors have equal value (gradient = 0). Search wanders or halts.
  • Ridge: Narrow slope with steep drops on both sides. Single orthogonal steps fail to climb.

Simulated Annealing (Escaping Traps)

Occasionally accepts worse moves with probability: P = e^(ΔE / T).

As Temperature T → 0 (cooling schedule), P → 0 &implies; behaves as pure hill climbing.

Mod 3 Genetic Algorithms & CSP
10 Marks ▼

Genetic Algorithm: 5 Steps

  1. Population: Set of chromosomes (bit strings).
  2. Fitness Function f(x): Evaluates chromosome quality.
  3. Selection: Roulette Wheel probability P(i) = f(i) / ∑f.
  4. Crossover: Swap bits between parents at split point (e.g. 11|00 + 00|11 → 1111).
  5. Mutation: Randomly flip a bit (prob ~0.01) to maintain genetic diversity.

Constraint Satisfaction Problems (CSP)

Defined by Variables X, Domains D, Constraints C (e.g. Map Coloring: adjacent regions ≠ same color).

  • MRV (Minimum Remaining Values): Choose variable with fewest legal values left ("fail-first").
  • Degree Heuristic: Choose variable with most constraints on other unassigned variables.
Mod 4 FOL Translation & Unification (MGU)
20 Marks ▼

The Golden Rule of FOL Translation

• ∀x (All/Every) ALWAYS pairs with → (Implication):
"Every student likes AI" &implies; ∀x (Student(x) → LikesAI(x))

• ∃x (Some/There is) ALWAYS pairs with ∧ (And):
"Some student likes AI" &implies; ∃x (Student(x) ∧ LikesAI(x))

Unification Algorithm (Finding MGU) - 3 Rules:

  1. Predicate Match: Outer predicate name and argument count must be identical. (Father vs Mother &implies; FAIL).
  2. Constant Clash: Two different constants CANNOT unify. (John vs Mary &implies; FAIL).
  3. Occurs Check: A variable cannot be unified with a term containing itself! (x vs Father(x) &implies; FAIL).

Resolution Refutation Proof (4 Steps)

  1. Convert all KB premises to CNF clauses.
  2. Negate the Goal: Add ¬Goal to clause set.
  3. Resolve complementary literal pairs: (A ∨ B) and (¬B ∨ C) &implies; (A ∨ C).
  4. Derive Empty Clause □ (Contradiction) &implies; Goal is proven true!
Mod 5 Bayesian Networks & Joint Probability
10 Marks ▼

1. Joint Probability Factorization

Multiply each variable conditioned on its direct arrows (parents):

P(X1, X2, ..., Xn) = ∏ P(Xi | Parents(Xi))

For chain A → B → C: P(A, B, C) = P(A) × P(B|A) × P(C|B)

2. Bayes' Rule Formula

P(A=T | B=T) = [P(B=T | A=T) × P(A=T)] / P(B=T)

Denominator P(B=T) = P(B=T|A=T)P(A=T) + P(B=T|A=F)P(A=F)

3. Rejection Sampling (Theory Points)

  • Generate thousands of random samples through network.
  • Reject (throw away) any sample where evidence condition (B=T) does not match.
  • Estimate probability = (matching survivors) / (total survivors).
Mod 7 NLP N-grams & Information Retrieval
10 Marks ▼

1. Bigram & Sentence Probability

P(w2 | w1) = Count(w1, w2) / Count(w1)

Sentence: P(<s> I like AI </s>) = P(I|<s>) × P(like|I) × P(AI|like)

2. Laplace (Add-1) Smoothing

Fixes the Zero Probability Problem (where an unseen word pair zeroes out the entire sentence):
P_Laplace(w2 | w1) = [Count(w1, w2) + 1] / [Count(w1) + V]
(where V = total distinct vocabulary size).

3. Information Retrieval (IR) vs Information Extraction (IE)

  • IR (Google Search): Returns ranked list of relevant documents/webpages for a keyword query. Uses Inverted Index, TF-IDF, PageRank.
  • IE (Fact Extraction): Pulls structured entities (Name, Date, Price) from unstructured text into database tables.
Mod 1 Agents & PEAS Specification
10 Marks ▼

1. PEAS Specification (Autonomous Drone / Car)

  • P (Performance): Safety, speed, battery efficiency, delivery accuracy.
  • E (Environment): Farmland/roads, obstacles, weather, GPS signals, other drones.
  • A (Actuators): Motors, propellers, steering, camera gimbals, transmitters.
  • S (Sensors): Cameras, LiDAR, GPS, IMU (gyro/accelerometer), altimeter.

2. The 4 Agent Types (Ladder of Intelligence)

  1. Simple Reflex: Knee-jerk IF-THEN rules on current percept only. Zero memory. (Automatic door).
  2. Model-Based: Maintains internal memory of unobserved world state. (Roomba vacuum).
  3. Goal-Based: Uses search/planning to achieve a destination target. (Google Maps navigation).
  4. Utility-Based: Evaluates trade-offs using a utility function to maximize preference/score. (Smart cab balancing time vs toll cost).
Mod 6 STRIPS & Classical Planning
10 Marks ▼

1. STRIPS Action Representation (3 Components)

  • Preconditions: What must be true BEFORE action executes.
  • Add List: Facts that become TRUE after action.
  • Delete List: Facts that become FALSE after action.

Example: Action Move(x, y) &implies; Pre: At(x), Add: At(y), Del: At(x).

2. Progression vs Regression Planning

  • Progression (Forward): Searches from Initial State → Goal. High branching factor.
  • Regression (Backward): Searches backward from Goal → Initial State. Only considers relevant actions &implies; smaller branching factor!
  • Sensorless (Belief-State) Planning: Agent has zero sensors; plans across a set of all possible initial worlds simultaneously.
