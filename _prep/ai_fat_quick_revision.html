1. Solvability (Inversion Parity)

Flatten grid into a single row, completely skip the blank tile (_).
Count how many times a larger number precedes a smaller number.
Both EVEN or both ODD &implies; SOLVABLE! (One Even & one Odd &implies; Unsolvable).

Mod 3 Alpha-Beta Pruning (Game Trees)
10 Marks ▼

The Rules in 2 Sentences:

• At MAX nodes: update α = max(α, child).
• At MIN nodes: update β = min(β, child).
• ✂️ Cutoff Condition: Whenever α ≥ β, PRUNE all remaining children of that node!

💡 Practiced 10-Mark Game Tree Trace
A (MAX) [α=-∞, β=+∞] / \ B (MIN) C (MIN) / \ / \ D (MAX) E (MAX) F (MAX) G (MAX) / \ / \ / \ / \ [2] [3] [5] [9] [0] [1] [7] [5]
  1. Node D (MAX): Sees 2, then 3 &implies; D = 3. Returns 3 to parent B.
  2. Node B (MIN): Updates β = min(+∞, 3) = 3. Window at B: [α=-∞, β=3].
  3. Node E (MAX): Inherits [α=-∞, β=3]. Sees child 5 &implies; updates α = 5.
    🚨 Cutoff: α ≥ β &implies; 5 ≥ 3 (TRUE!) &implies; Leaf [9] is PRUNED! Returns 5 to B.
  4. Back to Root A (MAX): B returns min(3, 5) = 3. Root updates α = max(-∞, 3) = 3. Window at Root A: [α=3, β=+∞].
  5. Right Subtree C (MIN): Inherits [α=3, β=+∞]. Node F evaluates 0, then 1 &implies; F = 1.
  6. Node C (MIN): Receives 1 from F. Updates β = min(+∞, 1) = 1. Window at C: [α=3, β=1].
    🚨 Cutoff: α ≥ β &implies; 3 ≥ 1 (TRUE!) &implies; Entire Subtree G and leaves [7, 5] are PRUNED!

Final Answer: Root Value = 3 | Optimal Path = A → B → D → [3] | Pruned = Leaf [9] and Subtree G [7, 5].

Mod 3 Hill Climbing (C1 FAT & Teacher's PPT)
10 Marks ▼

Concept:

Greedy local search. Keeps only 1 state in memory. Steps toward the neighbor with the highest value. Stops when no neighbor is higher.

💡 Practiced Problem 1: C1 FAT Question 4

Table of heights f(x): [1:3, 2:5, 3:7, 4:7, 5:6, 6:9, 7:8]. Start at x = 2.

  • At x = 2 (f=5): Neighbors x=1 (f=3), x=3 (f=7). Move right to x = 3.
  • At x = 3 (f=7): Neighbors x=2 (f=5), x=4 (f=7). Neither is strictly greater than 7! STOP.
  • Result: Returns local peak x = 3 with value 7.
  • Global Maximum: True maximum is at x = 6 with value 9!
  • Trap: Stuck on a flat Plateau / Local Maximum at x=3, 4.
💡 Practiced Problem 2: Teacher's Blocks World (PPT Slide 8)

Initial: [A on D, D on C, C on B, B on Table]. Goal: [D on C, C on B, B on A, A on Table].

• Local Rule (+1 correct, -1 wrong): Initial h = 0. Move A to table → h = 2. All next moves give h = 0 < 2 &implies; Stuck at Local Max (h=2), misses goal (h=4)!
• Global Rule (+1 support correct, -1 support wrong): Score strictly increases -10 → -5 → -3 → 0 → +10 &implies; Reaches Goal successfully!

Mod 4 FOL Unification (MGU) & Translation
20 Marks ▼

3 Rules of Unification (MGU)

  1. Predicate Match: Same name and same argument count.
  2. Constant Clash: Two different constants cannot unify (John ≠ Mary &implies; FAIL).
  3. Occurs Check: A variable cannot unify with a term containing itself (x vs Father(x) &implies; FAIL).
💡 Practiced: The 4 Pairs from Yesterday's C1 FAT (Q6)
  1. Father(x, Father(y)) & Father(John, Father(John))
    → x with John, y with John &implies; SUCCEEDS. MGU = {x/John, y/John}
  2. Loves(x, Father(x)) & Loves(y, y)
    → x/y &implies; Father(y) vs y &implies; FAILS (Occurs Check Violation)
  3. Ancestor(x, x) & Ancestor(John, Mary)
    → x/John &implies; compares John with Mary &implies; FAILS (Constant Clash: John ≠ Mary)
  4. Knows(x, Mother(x)) & Knows(John, y)
    → x/John &implies; y with Mother(John) &implies; SUCCEEDS. MGU = {x/John, y/Mother(John)}
💡 Practiced: FOL Translations (C1 & CAT-2)
  • "Every CS student who does not study will fail"
    ∀x ((CSStudent(x) ∧ ¬Studies(x)) → Fails(x))
  • "There is a professor liked by every student"
    ∃x (Professor(x) ∧ ∀y (Student(y) → Likes(y, x)))
  • "Any box that contains a smaller box is heavy"
    ∀x ∀y ((Box(x) ∧ Box(y) ∧ Contains(x, y) ∧ Smaller(y, x)) → Heavy(x))
Mod 5 Bayesian Networks & Joint Probability
10 Marks ▼

Core Formulas:

• Joint Probability: P(A, B, C) = P(A) × P(B|A) × P(C|B)
• Bayes' Rule: P(A|B) = [P(B|A) × P(A)] / P(B)

💡 Practiced Exam Question: Fire → Smoke → Alarm

Given: P(Fire=T) = 0.01 (so P(Fire=F) = 0.99)
P(Smoke=T | Fire=T) = 0.90  |  P(Smoke=T | Fire=F) = 0.05
P(Alarm=T | Smoke=T) = 0.80  |  P(Alarm=T | Smoke=F) = 0.01

1. Joint Probability that Fire, Smoke, and Alarm all happen:
P(Fire=T, Smoke=T, Alarm=T) = 0.01 × 0.90 × 0.80 = 0.0072 (0.72%)

2. Diagnostic Query: P(Fire=T | Smoke=T)
• Numerator = 0.90 × 0.01 = 0.009
• Denominator P(Smoke=T) = (0.90 × 0.01) + (0.05 × 0.99) = 0.009 + 0.0495 = 0.0585
• Result = 0.009 / 0.0585 = 90 / 585 ≈ 0.1538 (15.38%)

Mod 7 NLP N-grams & Information Retrieval
10 Marks ▼

1. Formulas:

• Bigram: P(w2 | w1) = Count(w1, w2) / Count(w1)
• Laplace (Add-1) Smoothing: P_Laplace = [Count(w1, w2) + 1] / [Count(w1) + V]

💡 Practiced 10-Mark NLP Problem

Training Corpus:
S1: <s> Sam likes green apples </s>
S2: <s> Sam likes green tea </s>
S3: <s> green tea is good </s>
Vocabulary: {Sam, likes, green, apples, tea, is, good, </s>} &implies; V = 8

1. Probability of sentence "<s> Sam likes green tea </s>":
= P(Sam|<s>) × P(likes|Sam) × P(green|likes) × P(tea|green) × P(</s>|tea)
= (2/3) × (2/2) × (2/2) × (2/3) × (1/2) = 4/18 = 2/9 ≈ 0.222 (22.2%)

2. Unseen Pair ("tea apples"):
• Without smoothing: 0/2 = 0 (causes zero-probability trap).
• With Laplace Smoothing: (0 + 1) / (2 + 8) = 1/10 = 0.1

2. IR vs IE (C1 FAT Q10b):

  • IR (Information Retrieval): Google search returning a ranked list of relevant documents/webpages for a query. Uses Inverted Index, TF-IDF, PageRank.
  • IE (Information Extraction): Extracting structured facts (Name, Date, Price) from unstructured text into a database table.

Mod 6 STRIPS & Classical Planning
10 Marks ▼

1. STRIPS Action Schema (3 Parts)

Action: Move(x, y) Preconditions: At(x) Add List: At(y) Delete List: At(x)

2. Progression vs Regression Planning (C1 FAT Q9a)

  • Progression (Forward): Searches from Initial State → Goal. High branching factor because many irrelevant actions are considered.
  • Regression (Backward): Searches backward from Goal → Initial State. Smaller branching factor because only actions that achieve an unsatisfied goal condition are explored.
